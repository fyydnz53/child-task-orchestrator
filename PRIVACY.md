# Privacy Notice

Effective date: August 11, 2026

Child Task Orchestrator is a skills-only Codex plugin. The plugin developer does not operate a server, user account system, analytics service, advertising service, or telemetry endpoint for this plugin.

The bundled Python helper makes no network requests. It writes task contracts, bindings, status, checkpoints, and handoffs to a `.codex-child-tasks/` directory in the local project selected by the user. That data remains under the user's control and can be removed by deleting that directory after it is no longer needed.

Users should not place passwords, API keys, access tokens, or other secrets in child-task titles, objectives, operation IDs, checkpoints, or handoffs.

Use of Codex and GitHub is governed by those services' respective privacy policies. Questions or concerns about this plugin can be filed through the repository's [GitHub issues](https://github.com/fyydnz53/child-task-orchestrator/issues).
